## 0.9.2 (2026-11-09)
Fixes from the first hardware checks of 0.9.1: the schedule's LEDs coming back on, Lights → Open OpenRGB, icons centred in the HUD pages' buttons, and night dimming / screen-off undone after a crash. Also 48 shortcuts with a paged app drawer and a better Steam picker, Sensor Manager Auto-pair, and FAN OK / STOPPED on Halo Gaming. Settings from 0.9.1 carry over.
- Fixed: the schedule's LEDs stayed off at the end of an off period when the lights had last been set from an OpenRGB profile that OpenRGB no longer lists. Lights on now uses the saved color in that case (and says so) instead of failing and retrying every minute. The schedule's status line no longer blames OpenRGB for every failure.
- Fixed: Lights page → Open OpenRGB gave up when OpenRGB's background service (no window, another Windows session) was found before the OpenRGB program. It also picked the first window titled "OpenRGB", which is one of a dozen hidden popup menus rather than the main window. It now looks only at copies on this desktop, picks the main window (one with a title bar), starts the program when only the service runs, and raises the window even when Windows won't hand focus over.
- Night dimming and schedule screen-off are undone after a crash too: while the backlight is lowered or the display is in standby, Pulsewave keeps a small record (display-restore.json beside settings.json); the next start puts the brightness back and wakes the display, then removes the record. Displays not connected at that start are left alone.
- Shortcuts: up to 48 (was 24). The app drawer shows 24 to a page with ‹ › page buttons, so its tiles keep their size. The Steam games picker starts with nothing ticked, has a search box, and counts the ticked games against the free slots (Add is disabled when they don't fit).
- Halo Gaming: the CPU card's fan reading is now FAN OK, turning red STOPPED only at 0 RPM (new data CPUFAN_STATE). Previous / next buttons on the Halo and monochrome templates, the editor's media widget and the Media page use outline icons like the quick actions; play / pause stays solid as the main button.
- Sensor Manager → Auto-pair (was Suggest missing): one click pairs every reading that is unpaired or no longer found with its clear best match, sets the scale from the reading's unit (KB/s → MB/s, GB → MB), lists what it paired and what HWiNFO doesn't export yet, and offers to save. Readings already paired to a live value are left alone; ties are left to you. It now recognises "Total CPU Utility", motherboard fan headers named just "CPU", PresentMon's displayed frame rate (never the 1% lows or frame time) and "Current UP rate", and refuses readings in the wrong unit (a GPU fan's % instead of RPM, °F temperatures). On this PC's HWiNFO export it picks the same 12 readings as the hand-made pairing.
- Fixed: icons sat low in the round buttons of the HUD's own pages (the expanded Now playing page most visibly: 4–6 px on the transport buttons, 3 px on ✕; also the Lights, Volume, Colors pages and the app drawer). A 0.18 em correction meant for theme text was also applied there, where the icon font's one-em line already centres the glyph. Measured from the font's glyph outlines, every Now playing icon is now within 0.7 px of its button's centre, and a regression check keeps it so. The play triangle moves slightly right (6% of its size) so it looks centred, on the pages and in themes.
- Fixed (from the release-candidate check): Open OpenRGB showed a blank window when OpenRGB was minimized to its tray icon. Qt keeps that window hidden, and showing it from outside leaves it undrawn; Pulsewave now sends OpenRGB's tray icon the message a double-click sends, so OpenRGB opens its own window (checked to have opened; otherwise the page says to double-click the tray icon).
- Fixed (from the release-candidate check): the app drawer's pages had different shapes (24 tiles in three columns, then 20 in two). With several pages, every page now uses the full page's grid, so tiles keep their size and place.
- Fixed (from the release-candidate check): the Now playing page's volume slider jittered while dragged, because Plexamp's volume reports (a beat behind the finger) redrew it. Sliders now ignore the device's readings while touched and for 2 s after; the Volume page's sliders do the same.
- Tests: `scripts/Run-Tests.ps1` builds and runs the regression suite in a new folder under work\test-runs, so a running Pulsewave never locks the build.

## 0.9.1 (2026-11-08)
Halo in three versions (Lifestyle, Gaming, Productivity), monochrome templates (Graphite, Paper, Noir), warning colors, tinted dock tiles, a reworked theme editor, refreshed older templates, gaming sessions, stale-sensor dimming, night dimming, performance-limit tags and an assignable tray double-click. Settings from 0.9.0 carry over; themes in use keep their template ids.
- Tray → Double-click the icon: choose what double-clicking Pulsewave's tray icon does. It can show the HUD (the default, as before) or show and hide it. It can open Themes, the playlist, Shortcuts, Gaming, the schedule, Telemetry or Sensor Manager. It can go to the next or previous theme, turn rotation on or off, or step the color palette. It can show the app drawer, media page or Lights page, switch the lights or aesthetic mode, show a chosen theme, or open a chosen shortcut. The choice is saved (new `TrayDoubleClick` setting), and older settings keep showing the HUD.
- Monochrome templates, each for the 8.8" bar and the HYTE Y70 column: **Graphite** (Halo's glass in greys: charcoal cards, white ring gauges, soft bevels), **Paper** (e-ink calm: warm off-white, black ink, hairlines instead of cards, a Georgia clock, segmented meters, outlined buttons) and **Noir** (poster black and white: Segoe UI Black, square corners, thick flat bars, an inverted play button). Each has the clock and weather (the column with the next hours), now playing with the album, system readings, network, the quick actions (Lights, Theme colors, Apps, Wallpaper) and, on the column, two rows of shortcuts. Album art, shortcut icons and game covers show in grey, and hot temperatures step up to the strongest ink rather than a color. New theme option Grayscale (album art and shortcut tiles).
- Second design review. Fixed: the drive temperature in Halo Productivity Column had no warning rule; the CPU load bar warned while the GPU's didn't (loads never warn now: busy is normal); Lifestyle showed memory without its total; VRAM read "8800MB" (now "9.6 / 16 GB", GPURAM_GB_OF, the total worked out from HWiNFO's memory load).
- Warning levels raised so gaming temperatures don't sit amber all session: CPU 90 / 98 °C, GPU 83 / 90 °C, drives 70 / 80 °C (Halo templates, editor widgets and starting values, and the refreshed older templates).
- Previews use realistic, consistent sample readings (memory text matches its bar, session peaks at or above current temperatures, colorful sample app icons that show the tinted tiles) instead of 88 everywhere. The quality gate also renders every template and widget with worst-case readings (100%, 99 °C, 5-digit fan speeds, GB/s, very long titles and names) and fails on overlaps or readouts leaving the screen; Spotlight and Daylight Column were adjusted for it.
- Stale sensors: when every HWiNFO reading has stood still for 30 s, or HWiNFO reports nothing, sensor readings dim on every theme, Classic's header says SENSORS PAUSED / OFFLINE, and themes can show it with SENSOR_STATUS. One static reading alone is never called stale.
- Night dimming: a schedule rule can dim the HUD (Schedule → Dim the HUD): darken the theme and drop its glows, lower the display's own backlight over DDC/CI (put back afterwards and when Pulsewave exits; not the main display, not in dock mode), or both, at 10–90% brightness.
- Performance limit tags: CPU_LIMIT and GPU_LIMIT show THERMAL / POWER / VOLTAGE LIMIT while HWiNFO reports one (new optional sensors in Sensor Manager with suggestions: CPU thermal throttling and power limit, GPU thermal, power and voltage limits; tick them for the gadget in HWiNFO). HWiNFO's Yes / No readings are understood.
- Halo redesign from the review: live FPS as the hero number with a labelled 60-second FPS chart, the session row in one format ("1h 24m"), a limit tag on the CPU and GPU cards, temperature and power large beside the ring with labels right above them, labelled load charts. Lifestyle gains the album, the next hours with "Rain from 18:00", condition-colored weather symbols, "Feels" only when it differs, labelled next days (on the column all in one weather card at the top, with the system rings last), one row of dock tiles and no network. Productivity gets one timer card (Timer / Stopwatch switch, Start or Pause as it applies, Reset, Pomodoro 25 / 5 and 50 / 10 that alternate by themselves), "resets in …" on AI limits with Claude Code and Codex set apart from the header, free drive space, and a now-playing strip. Every Halo template: spaced units ("142 W"), titles on up to two lines, grey state labels, a lighter date clear of the clock, centred quick toggles, and round buttons with a slight bevel and their icons centred.
- New theme options: SpacedUnit, MaxLines (text wraps onto that many lines), Bevel (panels). New data: MEDIA_ALBUM, WEATHER_RAIN, WEATHER_FEELS_NOTE, WEATHER_KIND / _D1_KIND / _D2_KIND, WEATHER_H1–H4 (TIME, ICON, TEMP, KIND, RAIN), DRIVE_FREE, DRIVE_USED_PCT, TIMER_ACTION, STOPWATCH_ACTION, TIMER_PHASE, FOCUS_CLOCK / MODE / ACTION / SWITCH, SENSOR_STATUS, CPU_LIMIT, GPU_LIMIT, GPURAM_GB_OF; formats "resets" (AI reset times), "short" (GAME_SESSION) and "month" (DATE). New tap actions: Pomodoro 25 / 5 and 50 / 10, and the timer card's start / pause, reset and switch. Weather also fetches the next 24 hours from Open-Meteo in the same request.
- Theme editor, past its L-Connect roots: the Halo look (dark rounded fields and drop-downs, rounded buttons, dark scroll bars and title bar) and a properties panel in folding sections (Position, Data, Tap action, Text style, Look, Warning colors, Glow). "Shows" opens a searchable picker in sections (CPU, GPU, Performance limits, Frame rate, Memory, Drives, Cooling, Network, Clock, Weather, Media, Volume, Timer & stopwatch, Gaming, AI usage, Shortcuts, Sensor feed). New controls: warning colors (with starting levels for the reading, low is bad, decided by another reading, own colors), shortcut tile style and name under the icon, a game-cover tile, date formats (long, short, month and day, custom) and clock formats (hours or minutes alone), and color pickers for gradients and glows. Editor widgets are rebuilt in the Halo kit, with new Quick toggles and a tinted, named Dock; all fit every screen shape and pass the quality gate.
- The older built-in templates (Glass Cards to Daylight Column) keep their layouts and gain the newer features: warning colors on temperatures, memory, VRAM and AI limits (bars and gauges only on Daylight's light cards), album art and track names that open the Media page, the track time in place of the PLAYING line, readable dates ("Dec 31" beside a weekday, otherwise "Thursday, Dec 31"), and tinted shortcut tiles. Every template still passes the quality gate in every palette.
- Halo in three focused versions, each for the 8.8" bar and the HYTE Y70 column. **Halo Lifestyle** (the former Halo and Halo Column; same template ids, so themes in use carry over) puts the clock, weather, now playing, the next days, quick toggles and the dock first. **Halo Gaming** (new) shows the game session (cover, session length, average / 1% low / live FPS, today and this week, peak temperatures) beside CPU and GPU cards with a load ring, temperature, power, clock and fan or VRAM, and a load history. **Halo Productivity** (new) has a timer and stopwatch with Start / Pause, +1 min and Reset, Claude Code and Codex limits with when they reset, system load bars and network. All six share one design kit: the same margins, padding and corners, one small-caps header style, one number style (Segoe UI Semibold; thin only for the clock), the long date ("Thursday, Dec 31"), calmer glows under more opaque glass, the weather's city with a location pin, labelled high and low and the next sunrise or sunset, track time as "2:41 / 4:03", memory as "10.8 / 32 GB", and the speaker as its own round mute button beside the volume track. The Colors toggle is now labelled "Theme colors".
- Warning colors: any text, value, bar or ring in a theme can turn amber at a warning level and red at a critical one (`WarnAt`, `CriticalAt`, optional `WarnColor` / `CriticalColor`), counting down for readings where low is bad (`LowIsBad`, for FPS) and optionally decided by another reading (`ColorBy`). Temperatures always compare in °C, even when shown in °F. Themes without these settings look exactly as before. The Halo templates use them for CPU (90 / 98 °C), GPU (83 / 90 °C), drive (70 / 80 °C) and memory (85 / 95%), AI limits (75 / 90%), and the 1% low (amber below 60% of the average FPS, red below 40%).
- Dock tiles: shortcut tiles can be "Tinted" (`TileStyle`): each app's tile takes a soft backdrop in its icon's main color, and system actions and key presses (Lock, Sleep, keys) are drawn as round glass buttons. `ShowLabel` names the shortcut under its icon. Existing themes keep their plain tiles.
- New theme data: RAM_GB_OF, MEDIA_TIME, GAME_FPS_LOW_PCT, WEATHER_SUN_NEXT and WEATHER_SUN_NEXT_LABEL; DATE formats "long" and "short"; media buttons use one solid icon set.
- Tray windows (Themes, Playlist, Shortcuts, Lights, Schedule, Weather, Gaming, Plex token, Sensor Manager, Telemetry and Polling & alerts) take the Halo look through one shared style (DesktopStyle.cs): a deep navy base with tinted panels and fields, light text with a soft secondary grey, rounded flat buttons (the main action sky blue, deletes rose), dark list headers and scroll bars, and a dark title bar tinted to the window (Windows 11; Windows 10 gets the dark title bar). Colorful controls such as the Lights color swatch keep their color. Date and time pickers stay in Windows' own colors.
- Visual polish: the CPU / GPU / System details page now matches the HUD's Halo / One UI look (tabs for the three pages, frosted reading rows with the charted one filled light, a glass chart card with the current value large, a sky-blue line over a soft gradient and the alert limit dashed in pink). The app drawer's glyphs, the editor's widgets (+ Widget) and its single elements (bar, chart, panel, line, shortcut tile) and new themes' background use the Halo palette instead of the old navy and mint. Classic keeps its Midnight look.
- Gaming detection beyond Steam: GOG Galaxy games (base games, not DLC), Xbox / Game Pass games (title and logo from MicrosoftGame.config), the games Windows itself has recognised (Game Bar's list, read defensively since its format isn't documented; programs that no longer exist are skipped), and games you add. Names come from the program's own details or its folder (Unreal Engine games use the folder above Binaries\Win64; code names, other-language titles and words like "Retail" or "-Win64" give way to readable names). When an unknown program runs full-screen with the GPU at least half busy for two minutes, the HUD asks "Track ‹name› as a game?" (Track / Never / not now; a tray notification too). Tray → Gaming… lists every recognised game and where it was found, games you added (Add a game… picks a program), programs that never count, and suggestions; suggestions can be turned off. The game list is built in the background.
- Gaming sessions: Pulsewave notices which game is running (every 5 s, from the programs behind visible windows, matched to installed Steam games and shortcuts in other stores' game folders; launchers, Discord and Wallpaper Engine never count; nothing is captured) and times each session, with its average FPS, 1% low (the slowest 1% of seconds), and peak CPU and GPU temperatures. Sessions of a minute or more are kept for 180 days in %LOCALAPPDATA%\Pulsewave\gaming.json. New theme values GAME_NAME, GAME_STATE, GAME_SESSION, GAME_FPS_AVG, GAME_FPS_LOW, GAME_PEAK_CPU, GAME_PEAK_GPU, GAME_TODAY and GAME_WEEK, and shortcut slot -1 shows the game's cover. A Gaming page (the "Gaming page" tap action) shows the session, play time today and over 7 days with a bar per game, and recent sessions. Halo and Halo Column gain a gaming card (the column's quick toggles become one row: Lights, Colors, Apps, Wallpaper; its CPU chart makes room), and the editor has a Gaming widget.

## 0.9.0 (2026-11-07)
Themes and a theme editor, the Halo and One UI looks, touch pages for media, volume, lights and colors, LED control through OpenRGB, a schedule, weather, aesthetic mode and color palettes. Settings from 0.8.0 carry over; settings for features removed since then stay untouched in settings.json.

- Colors page (the "Color palettes page" tap action, and the Colors button in the One UI and Halo templates): the current theme's own colors and every palette as preview tiles; tap one to recolor the theme (remembered for it). In those templates the Lights button now opens the Lights page instead of switching the lights.
- Sliders follow the finger: volume, brightness and Plexamp volume can be dragged (and still tapped), and the seek bar moves with the finger and seeks once where it lifts. A drag along a slider moves it; a vertical drag over a list scrolls it. The volume page (tall screens) and the Lights page's profiles and effects now scroll like the queue, so long lists are no longer cut short. With a mouse, sliders can be dragged too.
- Shortcut tiles: icons load trimmed of their transparent padding and draw larger (68% of the tile) with a soft shadow; icons that fill their square are rounded with a slight bevel (light top edge, soft shade below). Tall tiles show a Steam game's cover art (from Steam's local cache) filling the tile with rounded corners and the same bevel, including Steam links saved as desktop .url shortcuts. The app drawer's icons get the same treatment.
- Media page queue: shows the next 30 tracks (as far as Plexamp queues) and asks the Plex server for only those. Lists now follow the finger while dragging and glide on after a flick, slowing down like a phone's; a drag never taps a row.
- Halo, Pulsewave's signature style: built-in "Halo" (1920x480) and "Halo Column" (HYTE Y70) templates with blue, pink and green glows under dark tinted glass, a split clock with a glowing sky-blue colon, round album art in a track-progress ring with time played and left, ring gauges for CPU, GPU and memory with a CPU history chart, a blue-to-violet volume pill and round quick toggles. The HUD's volume, media and Lights pages take the same tint and slider fills. New theme data: MEDIA_PROGRESS, MEDIA_ELAPSED, MEDIA_REMAINING (Plexamp) and TIME formats "h" and "m" for hours and minutes apart. A slider's level no longer sits on the fill's edge.
- One UI templates: "One UI" (1920x480) and "One UI Column" (HYTE Y70 vertical) in the One UI look: glass cards over a soft gradient, a thin large clock, weather, now playing with round transport buttons and a volume pill slider (tap the speaker to mute, the slider for app volumes), system pill bars, round quick toggles (lights, colors, volume, apps, media, wallpaper/palette) and, on the column, rounded shortcut tiles. Generated from src/Tests/Themes/OneUiTemplates.cs.
- Fixed: on the Y70 the media page's transport buttons overlapped (the page is laid out 480 wide there); they now size to the room and each gets its own column. The play queue scrolls with a vertical swipe (or the mouse wheel) instead of running off the card, and a swipe never plays a track. The Lights page's status gets its own line on tall screens. Page checks now render at the real logical sizes.
- HUD pages restyled after Samsung One UI (OneUi.cs): soft dark gradient, frosted glass cards with large rounded corners, round buttons that fill light when on, and pill sliders whose light fill carries the icon with the level at the far end. Volume page: a pill slider per app (vertical on a bar, rows on a tall screen) with the app's icon, tap where the level should be, and a round mute button. Media page: round transport buttons with a big play button, slim seek bar, Plexamp volume slider, frosted queue rows. Lights page: round power buttons, brightness slider, round color swatches with a ring, profile and effect pills. App drawer: frosted tiles and a round close button.
- Media page (tap the Now playing widget's album art, or the "Media page" tap action): art, title, artist, a seek bar you tap, shuffle / previous / play-pause / next / repeat, and with Plexamp its own volume and the play queue (tap a track to play it). Plexamp's controls go to its local player on this PC; the queue is read from your Plex server with the stored token. Other players get play/pause and skip. Live-tested on Plexamp 2026-11-07: seek, volume, repeat, shuffle and jumping in the queue all applied and were put back.
- Color palettes: tray → Colors (or the "Next color palette" tap action) shows the current theme in one of 18 palettes (Synthwave, Ember, Forest, Ocean, Rose, Amber, Ice, Mono, Toxic, Sakura, Sunset, Arctic, Nightshade, Gold, Terminal, Neon city, Crimson, Lavender) or its own colors, remembered per theme. Theme files are never changed. Each color keeps its opacity; the main accent gets the palette's first; light themes are turned dark; text keeps the contrast it had. Every built-in template passes the quality gate in every palette. Pictures and videos keep their colors.
- Weather: tray → Weather finds your city (Open-Meteo, free, no account) and saves it with °C or °F. Themes get WEATHER_TEMP, _TEXT, _ICON, _FEELS, _HIGH, _LOW, _CITY, _SUNRISE, _SUNSET and the next two days (WEATHER_D1_/D2_ DAY, ICON, HIGH, LOW); L-Connect themes' "Weather" now shows too. New Weather widget in the editor. Fetched every 15 minutes only while a theme shows weather; only the typed city name (once) and the saved coordinates are sent.
- App volumes page (the Volume widget's APP VOLUMES button, or the "App volumes page" tap action): all sound plus every app with sound on the default playback device, playing apps first, each with its level, − / + (5 points) and mute as big tiles. Uses the Windows Core Audio session API, the same one the volume mixer uses; levels refresh each second while the page is open.
- Aesthetic mode (tray → Aesthetic mode, the "Aesthetic mode on / off" tap action, or a hotkey in Theme playlist / hotkeys): the HUD fades (10–40%) or hides so the wallpaper or screensaver under it shows. The first tap only wakes it; it then works normally and stays shown for the wake time after the last tap (1 minute by default, 30 s–10 min). A hidden theme's video pauses. Waking by tap needs click-through off.
- Lights: an Open OpenRGB button on the HUD's Lights page and in tray → Lights brings OpenRGB's window forward (also from its tray icon) or starts it, from where it was last seen running or Program Files. It never starts a second copy.
- Themes gallery shape filter: Show All shapes, Fits this display, Horizontal or Vertical, with a count of how many are shown. The choice is remembered (new `ThemeGalleryFilter` setting; older settings show everything). Square themes count as both orientations; unreadable themes appear under All shapes only. The playlist window has the same filter (shared setting): hidden themes stay ticked and in place, Move up/down steps over them, and the count notes ticked themes the filter hides.
- Fixed: after closing Apps, details or Lights on the touch screen, a tap could still hit the closed page's tiles (for example launching a game). Taps now skip hidden pages, and a page closed with ✕ no longer closes a different page 30 seconds later.
- Schedule (tray → Schedule · lights and screen off/on…): rules that turn the LEDs off and back on at set times on chosen days (overnight periods such as 23:00 → 07:00 work), and optionally blank the HUD to black, where a tap wakes it for a minute and drawing pauses while telemetry keeps running. The schedule acts only when a period starts or ends: lights switched by hand in between are left alone, and it only turns on lights it turned off. If OpenRGB doesn't answer, it tries again each minute. Screen off can also put the HUD's display in standby over DDC/CI (Windows' Monitor Configuration API) when the display supports it, and wake it for a tap or at the end of the period; never the main display or in dock mode, and the display is turned back on when Pulsewave exits.
- LED control through OpenRGB (this time Pulsewave drives the lights instead of following them). Tray → Lights · OpenRGB… picks the OpenRGB address and which devices to control, and sets any color, Off/On, brightness, effect speed, OpenRGB profiles and hardware effects. On the HUD, the new Lights page (theme action Lights page, or the + Widget → Lights buttons) has the same as big touch tiles; Lights on / off toggles them, and On brings back the last profile, effect or color. Colors use Direct mode where a device has it, else its own color mode; brightness uses a mode's own brightness or a dimmer color. Pulsewave talks only to OpenRGB's SDK server on this PC, only when asked, and never saves to device memory, saves or deletes profiles, or rescans.
- Theme editor colors: with several elements or a group selected, set a part (text, bar and gauge fill, track, card fill, borders, lines, gradient, glow) on all of them at once, or change any color they use to swap it everywhere in the selection. With nothing selected, Theme colors lists every color the theme uses to swap across the whole theme, and Select every… (or Select all like this on an element) picks all values, panels, gauges and so on to color them together. Each element keeps its own opacity unless the opacity is changed too.
- Theme editor groups: elements can share a group, and clicking any part picks the whole group so it moves, nudges, scales evenly from a corner, duplicates, deletes and reorders as one. Double-click a part (or pick it in the list) to edit it alone; Ctrl+click several and press Group (Ctrl+G) to make your own, Ungroup (Ctrl+Shift+G) to split. A group's properties set position, scale %, hidden, and the font and color of all its text at once. Themes without groups load as before.
- Theme editor + Widget menu: ready-made groups for a clock, CPU, GPU and memory cards, a GPU gauge, now playing with controls, network, volume with − and + buttons, timer, stopwatch, Claude and Codex usage, and four app shortcut tiles (given the next free slots). Each is centred on the theme and shrunk to fit small screens.
- Touching the HUD no longer moves the mouse cursor: the HUD handles touch and pen input itself instead of letting Windows turn it into mouse clicks, so a game keeps its cursor and aim. Windows' touch ripples and press-and-hold right-click are off on the HUD. If a touch driver still moves the cursor onto the HUD, it is put back.
- Y70 touch features (ideas from HYTE Nexus, no code taken): tray → Rotate HUD turns the whole HUD 90°, 180° or 270°, so a Y70 that Windows shows sideways runs vertical themes without changing Windows settings; a quick sideways swipe on the HUD goes to the next or previous theme; tray → Touch screen setup opens Windows' own touch calibration for touches that land on the wrong display; tray → Keep other windows off this display moves app windows that open on the HUD to the main display (full-screen windows are left alone).
- Shortcuts → Steam games… lists installed Steam games from Steam's own library files, with each game's icon, and adds the ticked ones. Shortcuts → Add action adds macro-style buttons: a keyboard shortcut sent to the app in front (Discord mute, OBS scenes), Lock PC and Sleep PC.
- New theme values and taps: VOLUME (L-Connect's Volume value now works too) and a speaker/mute icon, with volume up, down and mute taps through the Windows audio API; a countdown TIMER (start/pause, reset, +1 minute; a sound and notification when done) and a STOPWATCH. The editor's See-through background lets the desktop or a Wallpaper Engine scene show behind a theme's elements.
- Four more vertical templates for the HYTE Y70 Touch Infinite upright (682×2560): Pillar (neon CPU and GPU gauges, memory, network charts, compact now playing), Spin (music first: big album art and touch media buttons, then clock and system), Command Column (twelve shortcut tiles with All apps, Claude Code and Codex usage gauges, loads and temperatures) and Daylight Column (a light, Task Manager style card per component with charts).
- Dock mode for PCs without a spare display: tray → Dock to screen edge puts the HUD along the top, bottom, left or right of the selected display at 15–40% of its size, reserved like the taskbar (Windows app bar API) so maximized windows stop short of it. It stays on top except over a full-screen game or video on that display, gives the edge back when hidden or closed, and themes, rotation, details and the app drawer follow the slice's shape.
- Drag and drop shortcuts: drop programs, Start menu or Steam/Epic shortcuts, folders or web and steam:// addresses onto the Shortcuts window (onto a row to use that slot) or onto a shortcut tile on the HUD (click-through off) to put them in that tile's slot. Slots can be left empty (Clear slot) so later tiles keep their numbers.
- Shortcuts and an app drawer for opening games and programs from the HUD. Tray → Shortcuts lists up to 24 programs, games (.exe, Start menu and Steam/Epic shortcuts), folders and links, with their own icons. Themes show them through Shortcut tiles and Shortcut name values that refer to a slot number, so an imported theme can never open anything the user did not add; an Apps button opens a drawer with every shortcut as a big tile, laid out for the display's shape. The HUD still never takes focus, and the program it opens comes to the front.
- Claude Code and Codex usage: 5-hour and weekly plan limits (percent used and time to reset) as values, bars and gauges. Codex usage is read from Codex's own session logs. Claude usage has two opt-in sources under tray → Claude usage. Read from your Claude sign-in (for the desktop app) asks api.anthropic.com every 3 minutes, while a theme shows Claude usage, with the sign-in the Claude app keeps on this PC; the token is never saved, logged or renewed by Pulsewave, and this undocumented usage page may change. Terminal status line makes Pulsewave Claude Code's documented status line command (it also shows model, context and usage there); it changes only the statusLine setting, keeps a backup, and never replaces another status line.
- Three new templates: Launchpad (ten shortcut tiles, clock, temperatures and loads, All apps), Token Meter (Claude Code and Codex limit gauges with reset times) and Command Deck (tablet: twelve big shortcut tiles and all four usage gauges).
- Other screens: themes can be any size, so Pulsewave runs on a HYTE Y70 Touch Infinite (2560×682, or 682×2560 upright), vertical bars and tablets used as a desk HUD. The editor has a Screen size choice (presets plus custom width and height) and a new theme starts at the size of the selected display. Portrait themes, including imported L-Connect ones, are no longer refused. A theme shaped differently from the display is shown whole with bars of its own background color, and Classic fills a bar-shaped display as before but keeps its shape on others.
