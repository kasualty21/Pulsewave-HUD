# QA-01 — repeatable isolated release gate

Run from the workspace in Windows PowerShell with the .NET 10 SDK:

    .\scripts\Check-Release.ps1

Optional arguments: `-SourcePath <source-root>` and `-EvidenceDirectory <new-directory>`. The default evidence folder is unique under `work/`. `-CreateSourceArchive` creates and verifies a source candidate ZIP inside evidence only; final release assembly remains the coordinator's responsibility.

The script copies source into clean staging, excludes bin/obj and generated previews, records SHA-256 hashes, builds, runs regressions, publishes Windows x64 self-contained, checks the published product version, and confirms source hashes remain unchanged. Every dotnet command is checked for nonzero exit. Logs, SDK details, version, binary hash and success/failure evidence are retained. An optional archive is checked against every source hash. Existing evidence and immutable releases are never overwritten.

Regression artifacts use `GRAPHITE_TEST_OUTPUT_DIR`; source lookup uses `GRAPHITE_TEST_SOURCE_ROOT`. Without overrides artifacts go into a unique temporary folder. Tests render application-owned content off-screen. The script does not launch the overlay or the optional soak exercise, modify live settings/startup, or change display topology. Read-only monitor identity enumeration remains part of the existing regression suite.
