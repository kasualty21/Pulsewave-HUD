# V0.7.1 Pulsewave branding and upgrade acceptance

> Superseded on 2026-11-08: still-relevant items moved to `V0.9.1-ACCEPTANCE.md`, the one open checklist. Kept as history.

This release changes the product identity and storage locations while retaining V0.7.0 appearance and telemetry behavior. Compile/publish verification does not verify migration on the user's machine; complete the relevant checks after installing the new executable.

## Branding

- [ ] Confirm the dashboard's upper-left label, window titles, tray menu, and preview say Pulsewave.
- [ ] Confirm the executable is `Pulsewave.exe` and its file/product version is 0.7.1.
- [ ] Confirm the appearance preset list says Midnight, Ocean, Ember, Orchid and Ice; Midnight retains the former cyan Graphite color.
- [ ] Export session CSV and confirm the filename begins `pulsewave-session-` and the contents remain as expected.

## Upgrade continuity

- [ ] Exit the prior version before first launch. Confirm existing `%LOCALAPPDATA%\GraphiteMonitor\settings.json` is copied to `%LOCALAPPDATA%\Pulsewave\settings.json`; the original file remains unchanged.
- [ ] Confirm all 12 HWiNFO mappings, the game-independent FPS slot, monitor identity/scaling, opacity, profiles, telemetry settings and OpenRGB selection remain intact.
- [ ] Confirm legacy `Graphite` theme values in settings and saved profiles normalize to Midnight without changing the cyan palette.
- [ ] If Launch with Windows was enabled before upgrade, confirm it still appears enabled. Turn it off and on, then confirm the registry entry launches `Pulsewave.exe`; confirm no duplicate old entry remains.
- [ ] Restart and reload settings. Confirm the migrated values persist and the old settings folder remains available for rollback.
- [ ] Confirm overlay placement/recovery, click-through, always-on-top, hide/restore, startup, session stats/export and alerts still work.
- [ ] Keep Wallpaper Engine running underneath and confirm transparent overlay behavior and OpenRGB color following remain independent.

No settings, startup registration, display topology or application process was modified during compile/publish validation. Historical V0.5–V0.7.0 archives remain unchanged.
